仕様・注意点

  • 分割時に各パーツのSHA-256を記録した .parts.json マニフェストを生成します。
  • 結合時は、元ファイル名・連番・重複・欠損を先に検査し、マニフェストがあればサイズとSHA-256も照合します。
  • 大容量ファイルは端末の空きメモリやブラウザ仕様の影響を受けます。特に大きなパーツサイズではSHA-256計算時にメモリを使用します。
  • 生成したダウンロードURLはクリア操作やページ終了時に解放します。
